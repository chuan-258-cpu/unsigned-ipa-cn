# IPA 安装说明（Mac / 爱思助手）

本文用于安装 [原始 fchat_8.0.71.ipa](../ipa/original/fchat_8.0.71.ipa)（FChat，版本 `8.0.71`）。手机名称改为“微信”的版本位于 [ipa/sideload](../ipa/sideload/)。Mac 用户可用 Sideloadly 签名并安装；爱思助手的 IPA 签名教程目前主要按 Windows 版流程说明。

## 先说明一个限制

这不是可以直接在任意设备上打开的 App Store 安装包。每台设备都需要经过签名，推荐让**每位安装者使用自己的 Apple ID 签名并安装**。

- 免费 Apple ID 签名通常只能使用约 7 天，到期后需要重新签名安装。
- 付费 Apple Developer 账号的有效期和可用能力取决于证书、描述文件及设备登记情况。
- 不要把自己的 Apple ID 密码发给别人，也不要把自己用免费账号签出的 IPA 当成通用安装包分发。
- 签名后可能无法使用完整的推送、后台或扩展能力；FChat 多开版本的消息推送也不能保证与 App Store 版本一致。

## 安装前准备

1. Mac 用户：从 Sideloadly 官网下载 macOS 版：<https://sideloadly.io/>。如果使用 Windows，请从爱思助手官网下载最新版：<https://www.i4.cn/>。
2. 一根可以传输数据的 USB 线。
3. 一台 iPhone 或 iPad，系统版本至少为 iOS/iPadOS 15.0。达到最低版本不代表已验证所有设备的兼容性。
4. 一个用于签名的 Apple ID。对账号安全有顾虑时，建议使用专门的备用 Apple ID。
5. 下载完整的 IPA 文件：`fchat_8.0.71.ipa`（约 336 MB）。

文件信息：

```text
应用名称：FChat
版本：8.0.71
Bundle ID：com.tencent.fchat
最低系统：iOS/iPadOS 15.0
SHA-256：5af22c84d7bb1c415f4d9c861a43209497b8beb330194682888fec80c614b72d
```

## Mac 操作步骤

### 1. 安装并连接

1. 安装并打开 Sideloadly。仅从官网 <https://sideloadly.io/> 下载。
2. 用 USB 数据线连接 iPhone 或 iPad，保持设备解锁；首次连接时，在设备上点“信任”，输入锁屏密码。
3. 如果 Mac 上的 Finder 询问是否信任此设备，也点“信任”。
4. 打开 Sideloadly，确认设备出现在设备列表中。

### 2. 签名并安装 IPA

1. 把 `fchat_8.0.71.ipa` 拖到 Sideloadly 的 IPA 区域。
2. 选择要安装的 iPhone 或 iPad，再在 Apple ID 输入框填写你自己的美区 Apple ID。Mac 或手机上已有的登录不会自动完成签名。**Apple ID 的国家/地区不影响这个侧载流程，不需要把美区 ID 改成国区，也不需要退出 iPhone 上的 App Store 账号。**
3. 点击“Start”开始签名和安装；在工具提示的窗口中自行输入账号密码，并按提示完成双重认证。不要把密码或验证码发给其他人。
4. 如有更改 Bundle ID 的选项，先保留 IPA 自带的 `com.tencent.fchat`。只有工具提示此 ID 不可用且签名失败时才改成唯一 ID；改 ID 可能影响应用识别、与旧安装覆盖以及 FChat 的部分功能。
5. 等待 Sideloadly 显示安装成功。IPA 约 336 MB，期间保持设备连接、解锁和联网。

如工具提示需要额外配置，按当前版本提示和官方说明完成。

### 3. 在设备上信任并打开

安装完成后，按以下顺序检查：

1. 回到设备主屏幕，找到 FChat 图标。
2. 如果提示“不受信任的开发者”，打开“设置” > “通用” > “VPN 与设备管理”（部分系统显示为“设备管理”），选择对应的 Apple ID 或开发者项目，点“信任”。
3. 如果 iOS 16 或更高版本提示开启开发者模式，打开“设置” > “隐私与安全性” > “开发者模式”，开启后按提示重启设备，并在重启后的确认窗口中确认开启，再打开 FChat。
4. 首次打开应用时保持联网。若仍提示无法验证 App，先确认已完成信任，再重新签名安装。

### 4. 免费签名到期后续签

免费 Apple ID 签名通常 7 天到期。续签时在 Sideloadly 重新选择同一个 IPA、同一个 Apple ID 和同一台设备，再点“Start”；尽量保持 Bundle ID 不变并覆盖安装，**不要先卸载 FChat**，避免丢失聊天记录和本地数据。Sideloadly 提供自动刷新功能，但电脑需要运行相关后台服务，并在设备通过 USB 或已配置的 Wi-Fi 连接时完成刷新。

免费 Apple ID 还受同时安装应用数量和 App ID 创建数量限制。遇到限额提示时，按错误信息等待限制窗口过去，或使用具有相应权限的开发者账号。

## Windows 爱思助手操作步骤

爱思助手官方 IPA 签名教程：<https://www.i4.cn/news_detail_38195.html>。Mac 用户跳过本节。

1. 在爱思助手中打开“工具箱” > “IPA 文件签名”。
2. 点击“添加 IPA 文件”，选择收到的 `fchat_8.0.71.ipa`。
3. 选择“使用 Apple ID 签名” > “添加 Apple ID”，填写当前安装者自己的 Apple ID 和密码，并按提示完成双重认证。
4. 选择当前已连接设备的设备标识（UDID），再点击“确定”。签名后的 IPA 和设备标识绑定。
5. 勾选 IPA 与 Apple ID，选择签名文件保存目录，点击“开始签名”。
6. 签名完成后打开签名文件保存目录，找到新生成的已签名 IPA；在爱思助手“应用游戏”或设备应用列表中选择“导入安装”。签名工具本身不会自动完成安装。

免费 Apple ID 签名通常有效 7 天。每次签名都需选择准备安装的设备。

## 把文件发给别人时怎么做

建议直接发送原始文件 `fchat_8.0.71.ipa`，并让对方按本文相应电脑系统的步骤操作：

1. 对方在自己的 Mac 上安装 Sideloadly，或在 Windows 电脑上安装爱思助手。
2. 对方连接自己的 iPhone 或 iPad。
3. 对方使用自己的 Apple ID 签名并安装。
4. 到期后由对方重新签名，不需要向你索要 Apple ID 密码。

续签时优先使用同一个 Apple ID、同一台设备和相同的应用标识，重新签名后尝试覆盖安装。**不要先卸载 FChat**，卸载通常会删除应用内的聊天记录和其他本地数据；需要卸载时先完成应用内的数据备份或迁移。

如果希望由一个人统一签名后安装到多台设备，需要使用合规的 Apple Developer 账号、正确的签名证书和描述文件，并把目标设备登记到描述文件中；签名结果不能保证适用于未登记的设备。企业证书的可用性也不稳定，不建议把它当成长期分发方案。

## 常见问题

### Sideloadly 或爱思助手找不到 iPhone 或 iPad

确认设备已解锁并点过“信任”，更换 USB 线和接口后重新连接。Mac 上检查 Finder 是否能看到并信任设备，再退出并重新打开 Sideloadly；Windows 用户重新安装爱思助手提供的 Apple 驱动。

### 签名失败或提示描述文件不可用

确认 Apple ID 登录成功、设备已经连接，并检查免费账号是否达到设备或 App ID 数量限制。Sideloadly 用户按提示完成 Apple 验证；爱思助手用户可重新添加 Apple ID，或改用具有相应权限的开发者账号。不要只重复点击安装，因为未成功签名的 IPA 仍然无法安装。

### 安装成功但打开后立即闪退

先确认系统版本不低于 iOS/iPadOS 15.0，并重新用当前设备的 Apple ID 签名。若仍闪退，通常是签名权限、应用自身兼容性或 IPA 内容导致，爱思助手无法修复应用内部问题。

### 提示“无法验证 App”或“开发者不受信任”

保持设备联网，在“设置” > “通用” > “VPN 与设备管理”中信任对应项目；信任后仍失败，重新签名并尝试覆盖安装。免费签名到期后也会出现类似现象，需要重新签名。必须卸载重装时先备份或迁移数据。

### 提示“设备未越狱”或设备标识不匹配

普通设备通过有效签名安装不需要越狱。先确认导入的是签名输出目录中的新文件，再确认签名时选择的 UDID 与当前设备一致；不一致时需要按当前设备重新签名。

### 安装后收不到推送

侧载应用的推送、后台运行和扩展能力取决于 IPA 本身及签名权限。FChat 多开包不能保证具备官方 App 的全部推送能力，这不一定是爱思助手安装失败。

## 安全提醒

只从可信来源获取 IPA，并在发送前用 SHA-256 校验文件是否被替换。安装修改过的应用前先备份重要数据；Apple ID 密码和双重认证验证码不要交给其他人。
